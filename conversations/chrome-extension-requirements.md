# Vocabeat Chrome拡張機能 要件定義書

## 1. プロジェクト概要

### 1.1 目的
Google翻訳で翻訳された英単語を自動的に検知し、Vocabeat学習システムに単語として登録するChrome拡張機能を開発する。

### 1.2 対象ユーザー
- 日本のITエンジニア
- 英語学習を効率化したい開発者
- Google翻訳を頻繁に使用する技術者

## 2. 機能要件

### 2.1 基本機能

#### 2.1.1 Google翻訳検知機能
- **対象サイト**: https://translate.google.com/
- **検知タイミング**: 翻訳実行後
- **検知対象**: 英語→日本語の翻訳結果
- **検知方法**: DOM要素の変更監視

#### 2.1.2 単語情報抽出機能
- **英単語**: 翻訳元テキストから英単語を抽出
- **日本語意味**: 翻訳結果から日本語の意味を取得
- **コンテキスト**: 翻訳された文章全体を保存
- **URL**: 翻訳を実行したページのURL
- **タイムスタンプ**: 翻訳実行日時

#### 2.1.3 単語フィルタリング機能
- **単語長**: 2文字以上の英単語のみ対象
- **品詞判定**: 名詞、動詞、形容詞、副詞を優先
- **重複排除**: 既に登録済みの単語は除外
- **ストップワード**: 一般的すぎる単語（the, is, andなど）は除外

#### 2.1.4 データ送信機能
- **送信先**: VocabeatのREST API
- **認証**: ユーザートークンによる認証
- **データ形式**: JSON形式
- **エラーハンドリング**: 送信失敗時の再試行機能

### 2.2 ユーザーインターフェース機能

#### 2.2.1 拡張機能ポップアップ
- **ログイン状態**: Vocabeatアカウントとの連携状況表示
- **統計情報**: 今日取得した単語数、累計単語数
- **設定項目**: 自動取得ON/OFF、対象言語設定
- **履歴表示**: 最近取得した単語5件程度

#### 2.2.2 通知機能
- **取得通知**: 新しい単語を取得した際の通知
- **エラー通知**: 送信失敗やログアウト状態の通知
- **統計通知**: 1日の終わりに取得単語数のサマリー

#### 2.2.3 右クリックメニュー
- **手動追加**: 選択したテキストを手動で単語として追加
- **翻訳＆追加**: 選択したテキストをGoogle翻訳で翻訳し、結果を単語として追加

### 2.3 設定・管理機能

#### 2.3.1 設定画面
- **アカウント連携**: Vocabeatアカウントとの連携設定
- **自動取得設定**: 取得する単語の条件設定
- **通知設定**: 通知の種類とタイミング設定
- **除外設定**: 特定のサイトやドメインを除外

#### 2.3.2 データ管理
- **ローカルストレージ**: 一時的なデータ保存
- **同期**: Chrome同期機能との連携
- **エクスポート**: 取得した単語データのエクスポート

## 3. 技術要件

### 3.1 開発環境
- **言語**: TypeScript
- **フレームワーク**: Chrome Extension Manifest V3
- **ビルドツール**: Webpack または Vite
- **パッケージマネージャー**: npm

### 3.2 Chrome拡張機能仕様
- **Manifest Version**: 3
- **必要な権限**:
  - `activeTab`: アクティブタブへのアクセス
  - `storage`: ローカルストレージアクセス
  - `notifications`: 通知機能
  - `contextMenus`: 右クリックメニュー
  - `https://translate.google.com/*`: Google翻訳サイトへのアクセス

### 3.3 API連携
- **認証方式**: JWT トークン
- **通信プロトコル**: HTTPS
- **データ形式**: JSON
- **エンドポイント**: 
  - `POST /api/words` - 単語登録
  - `GET /api/auth/verify` - 認証確認
  - `GET /api/words/check` - 単語重複確認

## 4. セキュリティ要件

### 4.1 データ保護
- **個人情報**: ユーザーの翻訳履歴は暗号化して保存
- **認証情報**: アクセストークンは安全に保管
- **通信**: 全ての通信はHTTPS暗号化

### 4.2 プライバシー
- **データ収集**: 必要最小限のデータのみ収集
- **同意取得**: 初回利用時にプライバシーポリシーへの同意
- **データ削除**: ユーザーがデータ削除を要求できる

## 5. パフォーマンス要件

### 5.1 応答性
- **検知遅延**: 翻訳完了から1秒以内に単語を検知
- **UI応答**: ポップアップの表示は0.5秒以内
- **API通信**: 単語登録APIへの送信は3秒以内

### 5.2 リソース使用量
- **メモリ**: 20MB以下
- **CPU**: バックグラウンド処理でのCPU使用率5%以下
- **ストレージ**: ローカルストレージ使用量10MB以下

## 6. ユーザビリティ要件

### 6.1 使いやすさ

### 6.2 多言語対応
